# MGIT PYQ Hub — Backup & Disaster Recovery Guide

## 1. Database Backups (Supabase)
- **Automated Daily Backups:** Managed by Supabase Pro/Team plans.
- **Manual CLI Database Dump:**
  Run the Supabase CLI to export schema and data:
  ```bash
  supabase db dump --project-ref nnqhtpuylejrahgfklzw -f supabase/backups/dump_$(date +%Y%m%d).sql
  ```
  *(Store database dumps securely in an off-site private vault; never commit SQL dumps containing user data to public GitHub).*

---

## 2. Google Drive Source Safety
- Because the authoritative PDFs live in Google Drive, the database contains only relational metadata and file pointers.
- If the database is lost or corrupted, the entire question index can be regenerated by re-running the idempotent ingestion pipeline on the Google Drive folder.
