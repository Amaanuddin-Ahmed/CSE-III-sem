3. REMAINING ITEMS & KNOWN LIMITATIONS
--------------------------------------------------------------------------------
1. Live Gemini API Key Configuration:
   - /api/gemini serverless proxy is functional, rate-limited, and supports Gemini 2.5 Flash
     with fallback models.
   - However, GEMINI_API_KEY environment variable is not currently set in the Vercel dashboard.
   - Until added, /api/gemini returns AI_NOT_CONFIGURED (503) and the UI seamlessly shows
     the built-in fallback card ("Use your own AI" with 1-tap ChatGPT & Gemini prompt prefill).

2. Unit 3 Academic Question Classification:
   - 217 questions in Unit 3 across subjects lack granular topic tagging for Mid-1 vs Mid-2.
   - Currently, these appear in Semester End and are conservatively hidden in Mid-1/Mid-2
     to ensure zero out-of-syllabus questions are presented to students studying for midterms.

3. Content Gaps (Authentic Data Only):
   - Software Engineering (SE): Drive folder lacks verified unit note PDFs.
   - Environmental Studies (ES) & Innovation & Entrepreneurship (I&E): Limited PYQ papers.
   - Honest empty states are rendered with direct links to the WhatsApp contribution flow (916303191696).


4. KEY ENGINEERING SUGGESTIONS FOR NEXT AGENT / DEVELOPER
--------------------------------------------------------------------------------
[Suggestion 1] Vercel Environment Variable Setup:
   Add GEMINI_API_KEY to Vercel via CLI:
     vercel.cmd env add GEMINI_API_KEY production
   Or in Vercel Dashboard: Project Settings > Environment Variables > GEMINI_API_KEY.

[Suggestion 2] Semi-Automated Unit 3 Question Classifier:
   Build an offline script that reads data/syllabus.mr25.sem3.json and compares
   Unit 3 question texts using cosine similarity or token overlap against Unit 3 Part 1
   and Part 2 topics, generating candidate split tags for manual student review.

[Suggestion 3] Paper Ingestion Workflow (OCR via Marker):
   When new papers arrive via WhatsApp:
   1. Place PDF in docs/_work/papers/
   2. Run: marker_single <pdf-path> --output_dir docs/_work/ocr/
   3. Run: node scripts/build_data.js to parse and append into pyq-data.js.

[Suggestion 4] Frontend Asset Pre-fetching:
   Add <link rel="preconnect" href="https://cdnjs.cloudflare.com"> and
   <link rel="preconnect" href="https://fonts.googleapis.com"> to index.html for
   an additional 150ms reduction in initial Largest Contentful Paint (LCP) on Slow 4G.
